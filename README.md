# numpy-matplotlib-data-analysis

Practice with NumPy arrays and Matplotlib: 30 values reshaped into a 5-year × 6-month matrix, then analysed and plotted.

```bash
pip install -r requirements.txt
python analysis.py
```

What it does: reshape to 2-D, mean per year / per month, locate the maximum, percent change between the first and last year, line charts per year and a 3×2 dashboard.
